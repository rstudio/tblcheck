# Deprecated Generics

These generics are now deprecated.

## Usage

``` r
tblcheck_grade(problem, ...)

tblcheck_message(problem, ...)
```

## Functions

- `tblcheck_grade()`: is now
  [`problem_grade()`](https://rstudio.github.io/tblcheck/v0.2.1/reference/problem_grade.md).

- `tblcheck_message()`: is now
  [`problem_message()`](https://rstudio.github.io/tblcheck/v0.2.1/reference/problem_message.md).
